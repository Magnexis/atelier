# @magnexis/atelier

Atelier is Magnexis' local-first design language for React: portable tokens, explicit interaction contracts, and the Signal Ledger component family.

This package is prepared for JSR and is currently distributed from source while the `@magnexis` JSR scope is verified.

```ts
import { SignalToggle, LedgerField } from "@magnexis/atelier";
```

The initial JSR package publishes the JavaScript API and tokens. The source/Git package additionally carries `styles.css` and `signal.css` while Atelier prepares a compiled style distribution compatible with JSR.

The public API is defined in `src/index.js`. See the repository README for the Studio, release process, and MCP discovery endpoint.
