03 / A DIFFERENT WORKFLOW

Designing and building are no longer separate handoffs.

Atelier treats the interface as source material. Teams can work visually, in code, or both—each change resolves to the same portable design contract.

See the package anatomy →
  1. 1Define

    Establish semantic color, type, spacing, motion, and layout tokens.

  2. 2Prototype

    Assemble responsive, interactive patterns in the local Studio.

  3. 3Commit

    Export portable tokens and components to the repository you already own.

  4. 4Validate

    Run behavior and accessibility contracts alongside your application tests.

04 / THE PACKAGE

A design language your repository can understand.

Atelier is framework-light. The base package contains tokens and a small React layer. More involved interactions are composed from first-party recipes, not opaque generated bundles.

  • ✓ ESM package with explicit exports
  • ✓ React is a peer dependency, never bundled
  • ✓ CSS custom properties for any stack
  • ✓ Contract-first testing model
npm install @magnexis/atelier

# Then import the global design contract:
import "@magnexis/atelier/styles.css";
